# Action method files

One file per workflow action, named `<action>.md`, each with the same
sections so the primary agent can read any of them the same way:

1. **When** — what the developer asked for or what state calls for it.
2. **Run** — the helper command(s), in order, and what each result means.
3. **Method** — how to do the work the helper does not do.
4. **Report** — what to tell the developer, and what to ask.
